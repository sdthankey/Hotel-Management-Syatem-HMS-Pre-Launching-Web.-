# Hotel Management System (HMS) - Pre-Launching 🏨

A professional, high-end hospitality management platform designed to provide a seamless booking experience and efficient hotel operations management. Built with a clean architecture using separate frontend layers.

## 🚀 Live Preview
Experience the project live: [shyamthanki.com/hms](https://shyamthanki.com/hms)

## ✨ Core Features

### 1. Smart Booking Interface
- **Availability Checker:** Integrated date-picker system for check-in and check-out.
- **Instant Search:** Quick filtering for available rooms based on guest requirements.

### 2. Luxury Accommodation Display
- **Room Categorization:** Detailed cards for Luxury, Deluxe, and Standard suites.
- **Amenity Highlighting:** Visual badges for WiFi, AC, Smart TV, and Room Service.
- **Dynamic Pricing Display:** Clear pricing structure for different room types.

### 3. Guest Services & Experience
- **Facilities Showcase:** Dedicated sections for Fitness Center, In-house Dining, and Laundry services.
- **Testimonial Slider:** Professional display of guest reviews and ratings to build trust.
- **Interactive Gallery:** High-quality imagery showcasing the hotel's ambiance.

### 4. Technical Excellence
- **Modular Code:** Separated concerns with dedicated `index.html`, `style.css`, and `script.js` files.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens using modern CSS techniques.
- **Modern UI/UX:** Clean aesthetics with smooth hover effects and intuitive navigation.

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Architecture:** Multi-file structure for better maintainability.
- **Fonts:** Inter & Playfair Display (via Google Fonts)
- **Deployment:** Custom Domain with Cloud Management.
